### CVE-2026-41242 — protobufjs Code Injection
- **Date:** 2026-04-20 · **Source:** [nvd.nist.gov](https://nvd.nist.gov/vuln/detail/CVE-2026-41242) · **Class:** cve
- **What:** Arbitrary code execution through malicious `type` fields during protobuf object decoding. Affects < 8.0.1 / < 7.5.5.
- **Why it matters:** Any Node.js/browser app that decodes user-supplied protobuf is exploitable. Widely deployed library.
- **Hunt signal:** Find apps decoding user-controlled protobuf data. Grep for `protobufjs` in `package.json`, check version. PoC exists.
- **Evidence:** [source] NVD · [opinion] Critical. Deserialisation with user-supplied class names = classic gadget chain.

### CVE-2026-40948 — Apache Airflow Keycloak OAuth CSRF / Session Fixation
- **Date:** 2026-04-20 · **Source:** [nvd.nist.gov](https://nvd.nist.gov/vuln/detail/CVE-2026-40948) · **Class:** cve
- **What:** Missing OAuth `state` parameter and PKCE in the Keycloak provider allows login-CSRF and session fixation.
- **Why it matters:** Any realm account can hijack a victim's Airflow session to exfil stored Connection credentials.
- **Hunt signal:** Intercept Keycloak login redirects — missing `state=` in the redirect URL is the tell. Affects `apache-airflow-providers-keycloak` < 0.7.0.
- **Evidence:** [source] NVD · [inference] Session fixation via crafted callback; no user interaction beyond clicking a link.

### CSS Injection via HTML Email Attribute Sanitizer Bypasses (4 findings)
- **Date:** 2026-04-20 · **Source:** HackerOne Hacktivity · **Class:** writeup
- Four distinct bypasses against CSS/HTML email sanitizers disclosed on H1 today:
  1. **SVG filter primitives** bypass remote image blocking → email tracking pixel via `<feImage>`.
  2. **`position: fixed !important`** bypasses CSS sanitizer's fixed-position mitigation.
  3. **Unquoted `body background` attribute** enables CSS injection bypassing sanitizer.
  4. **SMIL `values` and `by` attributes** bypass remote image blocking via unvalidated SVG animation.
- **Why it matters:** Email tracking and CSS injection via HTML sanitizer gaps — good targets for webmail programs (Gmail, Yahoo, Outlook, HEY, Fastmail).
- **Hunt signal:** Fuzz HTML email rendering endpoints. Try SVG `<feImage>` tags and unquoted HTML attribute injection in email body parsers.
- **Evidence:** [source] H1 hacktivity (4 public disclosures today)
