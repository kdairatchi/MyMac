## 1. Top CVE today

### Adobe ColdFusion RDS Path Traversal → File Write → RCE (CVE-2026-48282)
- **Date:** 2026-07-07 · **Source:** [NVD](https://nvd.nist.gov/vuln/detail/CVE-2026-48282) · **Class:** cve
- **CVE:** CVE-2026-48282
- **Affected:** Adobe ColdFusion 2023 ≤ 2023.20 / ColdFusion 2025 ≤ 2025.9
- **CVSS:** 10.0 — [NVD](https://nvd.nist.gov/vuln/detail/CVE-2026-48282)
- **KEV:** YES — exploitation detected in the wild July 2, 2026 (KEVIntel honeypot data); CISA catalog confirmed
- **What it lets you do:** Unauthenticated attacker traverses the RDS FILEIO handler to write arbitrary files anywhere on the server filesystem, including web root — yields unauthenticated RCE. Also enables arbitrary file read for cred/source exfil.
- **Condition:** RDS must be enabled AND RDS auth disabled (non-default). ColdFusion admins commonly disable RDS auth for dev convenience and leave it on in production.
- **PoC:** PUBLIC — active exploitation confirmed; Resecurity technical analysis: https://www.resecurity.com/blog/article/cve-2026-48282-adobe-coldfusion-rds-path-traversal-leading-to-rce · BleepingComputer: https://www.bleepingcomputer.com/news/security/max-severity-adobe-coldfusion-flaw-now-exploited-in-attacks/
- **Relevant programs:** Adobe HackerOne program (adobe.com); any enterprise program with ColdFusion in scope (financial services portals, healthcare, US gov contractors). Scope research required for non-Adobe programs.
