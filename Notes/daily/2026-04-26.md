### CVE-2026-24126 — Weblate SSH Argument Injection → File Disclosure
- **Date:** 2026-04-26 · **Source:** [HackerOne #3518571](https://hackerone.com/reports/3518571) · **Class:** writeup/cve
- **What:** Admin can inject CLI args into `host` param in Weblate's `/manage/ssh/` endpoint — reads `/etc/passwd`, `settings.py`, private SSH keys via `subprocess` without `shlex.split` or `shell=False`.
- **Why it matters:** Any Weblate instance with admin creds (or admin-level IDOR) → full cred dump. Pattern reusable across translation tools with SSH key management.
- **Hunt signal:** POST `/manage/ssh/` with `host=-o ProxyCommand=cat /etc/shadow` → check response. Grep: `rg -n 'subprocess.*(ssh|scp)' src/ | rg -v 'shlex\.split|shell=False'`
- **Evidence:** [source] https://hackerone.com/reports/3518571
