### SharePoint RCE via .NET Deserialization Added to CISA KEV (CVE-2026-45659)
- **Date:** 2026-07-04 · **Source:** [nvd.nist.gov](https://nvd.nist.gov/vuln/detail/CVE-2026-45659) · **Class:** cve
- **What:** Authenticated attacker with SharePoint Site Member perms deserializes untrusted data server-side for RCE; no admin required.
- **Why it matters:** CISA KEV addition (deadline today, 2026-07-04) confirms in-the-wild exploitation; same .NET deserialization class recurs across enterprise .NET webapps in bug bounty scope.
- **Hunt signal:** `curl -si https://target/ | grep -i "MicrosoftSharePointTeamServices"` for version fingerprint; probe `__VIEWSTATE` parameters on any IIS/.NET target for MAC validation bypass
- **Evidence:** [NVD](https://nvd.nist.gov/vuln/detail/CVE-2026-45659) · [CISA KEV](https://www.cisa.gov/news-events/alerts/2026/07/01/cisa-adds-one-known-exploited-vulnerability-catalog) · [The Hacker News](https://thehackernews.com/2026/07/sharepoint-rce-cve-2026-45659-added-to.html)
