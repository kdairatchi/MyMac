## 2. Writeup of last 72 hours

**H1 Disclosed: Nextcloud — Auth Bypass via Missing JWT Signature Verification in user_oidc (CVE-2026-45156)**

- **Target type:** Web / API (SSO/OIDC flow)
- **Bug class:** Authentication bypass (CWE-347 — Improper Verification of Cryptographic Signature)
- **Aha moment:** The user_oidc plugin's ID.me handling path never verified the JWT signature; a forged unsigned token logged in as any user. Zero brute-force, zero credentials.
- **Hunt recipe:**
  1. Find an OIDC callback endpoint on target (look for `/index.php/apps/user_oidc/code` or generic `/oauth/callback`).
  2. Intercept the JWT in the callback. Send a copy with `"alg":"none"` and no signature — if 200 returns, full bypass confirmed.
  3. Set `sub` to an admin's email/username in the payload and re-issue.
- **Kill criterion:** Target responds 401 on `alg: none` token and validates against a registered JWK — stop immediately, don't dig deeper.
- **Source:** [redpacketsecurity.com](https://www.redpacketsecurity.com/hackerone-bugbounty-disclosure-authentication-bypass-in-id-me-handling-via-missing-jwt-signature-verification-in-user-oidc-priyanka/)
