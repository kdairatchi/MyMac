### I Made OpenID Connect Stop Checking Signatures (2026-06-25)
- **Date:** 2026-06-27 · **Source:** [medium-writeups tracker](https://github.com/rix4uni/medium-writeups) · **Class:** writeup
- **What:** OIDC JWT signature verification bypassed via Authlib JWK header injection or `alg: none` on a real BB target. Token forged, protected endpoints accessed.
- **Why it matters:** Authlib ≤ 1.6.6 affected; common in Flask/FastAPI OAuth/OIDC integrations. Pattern: library trusts attacker-supplied algorithm in JWT header over server policy.
- **Hunt signal:** `pip show authlib | grep Version` on target app server; craft JWT `{"alg":"none"}` + empty sig and test protected endpoint
- **Evidence:** [GHSA-wvwj-cvrp-7pv5](https://github.com/lepture/authlib/security/advisories/GHSA-wvwj-cvrp-7pv5) · [GHSA-7wc2-qxgw-g8gg](https://github.com/lepture/authlib/security/advisories/GHSA-7wc2-qxgw-g8gg) · writeup title only (direct URL blocked)
