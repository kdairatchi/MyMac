### OWASP CRS Whitespace Padding Bypass — `CVE-2026-33691`

- **Tags:** `#rce` `#web`
- **Severity:** high · **Hunt:** 1/5 · **Score:** 7.0 · **Status:** patched · **Age:** 0d
- **Sources:** [1](https://github.com/coreruleset/coreruleset/security/advisories/GHSA-rw5f-9w43-gv2w)

- **Trick:** Attackers bypass file upload filters by padding malicious extensions (e.g., .php) with whitespace characters like tabs or spaces, which are normalized by Windows backends into valid extensions during file processing.
- **Why it matters:** This allows RCE through web shell uploads despite OWASP CRS protections, particularly impacting Windows environments where backend systems trim whitespace in filenames.
- **Rating:** chain-worthy (reusable technique for other WAF bypass scenarios)
Relevant for bug bounty hunters as it demonstrates nuanced file upload evasion tactics against security controls, highlighting the need to test normalization behaviors across different backend environments during pentests.
